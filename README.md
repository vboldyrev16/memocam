# Мемокам

**Твоё выражение лица → мем на камере.** Локальная камера с реакциями для друзей, созвонов и стримов.

Мемокам отслеживает лицо и кисти, показывает точки распознавания и запускает выбранную реакцию. Работает в браузере без аккаунта и облачной обработки кадров. Это экспериментальный продукт: видимые движения лица сопоставляются с игровыми реакциями, внутренние эмоции человека не определяются.

## Запуск

Нужны Node.js 22.12+ и современный Chrome/Chromium. Проверено на macOS; другие системы пока не прошли ручную проверку.

```sh
npm ci
npm run setup
npm run dev
```

Открой http://127.0.0.1:5173 и разреши камеру. На две секунды расслабь лицо и опусти руки. `setup` один раз скачивает две модели из Google Storage с проверкой SHA-256 и копирует WASM из установленного пакета. После установки обработка кадров работает локально. Если камера занята, закрой другие приложения, использующие её.

## Камера и предпросмотр

В списке «Камера» выбери встроенную или внешнюю веб-камеру. Выбор применяется сразу, запоминается в этом браузере и запускает повторную калибровку. Кнопка ↻ обновляет список. Если выбранная камера отключена, подключи её или выбери другую; приложение не переключается на неё автоматически после повторного подключения.

«Зеркало: вкл/выкл» над видео меняет только личный предпросмотр Мемокам, вместе с точками. Эта кнопка не управляет зеркальностью Google Meet. При включённой передаче в OBS кнопка «Кадр для звонка ↗» открывает чистый исходящий поток без второго захвата камеры. Дальнейшая обработка OBS или Meet в этом окне не отображается.

## Собери свою подборку

1. «Мой набор и тест» → отметь нужные пары «мем — действие».
2. «Моя подборка» показывает только выбранное. Галочки сохраняются автоматически, при перезагрузке не заменяются старым набором.
3. «Тестировать выбранные» показывает условия, удержание и журнал. Между реакциями возвращай нейтральное лицо.
4. «Перенести или сохранить настройки» скачивает JSON. Импорт применяется только после просмотра и нажатия кнопки. Медиафайлы и калибровка в JSON не входят.

H — библиотека; L — точки; пробел — пауза; F — полный экран. Для скепсиса, прищура и пальца у переносицы держи лицо примерно прямо: сильный поворот искажает взаимное положение точек. Белка запускается завершённым взмахом раскрытой ладони туда-обратно; дополнительное удержание не требуется. Для повтора опусти руку и подожди завершения клипа.

## Материалы

**В комплекте 48 мемов с настоящими изображениями, GIF, аудио и видеореакциями.** Файлы находятся в `public/media/`, сведения об источниках — в `public/media/sources.json`. Лицензия MIT относится к коду и не выдаёт разрешений на сторонние медиа. Отдельные подтверждения прав на распространение этих материалов не установлены.

Для своих материалов открой `/?studio=1`, выбери карточку → подробнее → добавь собственный файл. Затем вернись в камеру. Загрузки хранятся локально в браузере. Если материал требует удаления или исправления источника, создай issue с названием файла и ссылкой на оригинал.

Названия и ссылки в каталоге помогают подобрать оригиналы. Исторические категории персон не являются проверкой их текущего правового статуса. Для инструкции по каждому действию открой карточку или скачай полный список в приложении.

## Meet / Zoom через OBS

1. Установи OBS с виртуальной камерой. На macOS разреши расширение камеры в системных настройках, если OBS попросит.
2. Открой Мемокам: `http://127.0.0.1:5173/?send=1&compact=1`.
3. В OBS добавь Browser Source с адресом `http://127.0.0.1:5173/?output=1`, размером 1280×720. Запусти Virtual Camera.
4. В Meet/Zoom выбери OBS Virtual Camera. Оставь Мемокам работающим: закрытая или уснувшая вкладка прекращает обработку.

В звонок передаётся чистый кадр 1280×720 без интерфейса и точек. Камера заполняет кадр: у источника 4:3 немного обрезаются верх и низ, чтобы не добавлять боковые полосы. Мемы сохраняют свои пропорции. Звук мемов в микрофон не передаётся. OBS остаётся отдельным компонентом; это не подписанный нативный установщик виртуальной камеры. Самопроизвольный запуск встреч отсутствует.

## Разработка

```sh
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

React + TypeScript + Vite; MediaPipe работает в Web Worker. Код распознавания — `src/expressions.ts`, `src/gestures.ts`, калибровка — `src/realtime.ts`, личный выбор — `src/preferences.ts`. Встроенная передача в OBS использует локальный сервер Vite, поэтому одна статическая публикация на GitHub Pages не заменяет сервер звонков.

Не публикуй кадры камеры, персональные настройки и логи с секретами. Для сообщения о баге опиши действие, свет, поворот головы, браузер и состояние индикаторов; изображение лица необязательно. Код — MIT; условия сторонних компонентов: [THIRD_PARTY.md](THIRD_PARTY.md).

## Авторская подборка и изменения

В этой версии `src/author-preset.json` — пустой шаблон, а не опубликованная личная подборка. Для своей сборки можно импортировать экспорт выбранных действий:

```sh
node scripts/import-author-preset.mjs /path/to/memocam-settings.json
```

Скрипт оставляет только назначения выражений и ID выбранных действий. Непустой набор применяется при первом запуске и доступен через кнопку «Подборка автора». Существующий личный выбор, в том числе пустой, сохраняет приоритет. Исходный файл настроек коммитить не нужно.
